14.3. ДАНІ, ЩО ПЕРЕДАЮТЬСЯ З ПЗ ЕКОТЕСТ ДО HMI PANEL
----------------------------------------------------
14.3.1. Які дані потрібно відображати на HMI Panel?

       14.3.1.1. ПОТОЧНІ ВИМІРЮВАННЯ:
                - Поточне значення ПАЕД для кожного приладу (мкЗв/год)
                - Поточна температура для кожного приладу (°C)
                - Поточна активність для цистерн (Бк)
                - Стан детекторів (норма/відмова) для кожного приладу
                - Валідність результатів (дійсний/недійсний)
                - Статус спектру (накопичення/очікування/готовий) для цистерн

       14.3.1.2. СТАН ПРИЛАДІВ:
                - Статус зв'язку з приладом (норма/немає зв'язку)
                - Відображення можливих помилок:
                  * Втрата зв'язку з приладом (з зазначенням SN)
                  * Помилка CRC
                  * Хибний пакет даних
                  * Невдалий запуск набору спектру
                - Кількість невідповідей (опціонально)
                - Останній час успішного опитування

       14.3.1.3. СИСТЕМНА ІНФОРМАЦІЯ:
                - Статус програми (працює/зупинено)
                - Час безперервної роботи (uptime)
                - Статус з'єднання з БД (норма/помилка)
                - Вільне місце на диску для БД (попередження при < 10%)

       14.3.1.4. ПОДІЇ ТА ТРИВОГИ (в реальному часі):
                - Втрата зв'язку з приладом (з зазначенням SN)
                - Помилка CRC
                - Невдалий запуск спектру
                - Заповнення цистерни
                - Злив цистерни
                - Заміна приладу
                - Запуск/зупинка програми

14.3.2. Чи потрібно передавати статистику?
       - Середнє ПАЕД за зміну/добу/тиждень по кожному приладу
       - Максимальне/мінімальне ПАЕД по кожному приладу
       - Активність кожної цистерни за період

14.3.3. Чи потрібно передавати історію вимірювань (архів)?
       - За який період? (остання доба, тиждень, місяць)
       - З яким кроком? (кожне вимірювання, усереднене за годину)

14.7. ПРИКЛАДИ ДАНИХ ДЛЯ УЗГОДЖЕННЯ
-----------------------------------
14.7.1. ПОТОЧНІ ДАНІ (ОДИН РЕГІСТР/ЗМІННА):
       - Цистерна 1: заповненість (0=порожня, 1=повна)
       - Цистерна 1: ПАЕД (float, мкЗв/рік)
       - Цистерна 1: активність (float, кБк)
       - Цистерна 1: статус спектру (0=очікування, 1=накопичення, 2=готовий)
       - Кімнатний детектор 1: ПАЕД (float, мкЗв/рік)
       - Кімнатний детектор 1: температура (float, °C)
       - Загальний статус системи (0=норма, 1=помилка, 2=попередження)

14.7.2. ПОДІЇ (ПРИКЛАДИ):
       - Подія: connection_error, SN: 2400089, час: 2025-06-13 10:30:00
       - Подія: cistern_filled, № цистерни: 1, час: 2025-06-13 11:00:00
       - Подія: device_replaced, старий SN: 2400089, новий SN: 2400123, час: ...

14.7.3. ЧИ ПОТРІБНІ КОМАНДИ ВІД HMI PANEL ДО ПЗ ЕКОТЕСТ?
       - Встановити стан цистерни 1: повна / порожня
       - Скинути спектр для цистерни 1
       - Перезапустити систему
