8. АЛГОРИТМ АКТИВАЦІЇ ПРИЛАДУ
==============================

8.1. ПРИЗНАЧЕННЯ
----------------
Повернення раніше заміненого (або деактивованого) приладу до роботи без зміни
конфігурації системи та без фізичних маніпуляцій з адресою.

8.2. КОЛИ ЗАСТОСОВУЄТЬСЯ
-------------------------
- Прилад був замінений (is_active = 0), але повернувся після ремонту
- Прилад був деактивований вручну (наприклад, через DB Browser)
- Прилад фізично присутній, але з якихось причин неактивний в БД

8.3. АЛГОРИТМ РОБОТИ
--------------------

Етап 1: Відкриття діалогу
-------------------------
1. Адміністратор відкриває меню «Прилади» → «Заміна приладу»
2. Діалог завантажує список неактивних приладів з БД:
   - SELECT serial_number, location_type, position_number
     FROM devices WHERE is_active = 0
3. Випадаючий список «Неактивний прилад» заповнюється

Етап 2: Вибір приладу
---------------------
1. Адміністратор обирає прилад зі списку неактивних
2. (Опціонально) перевіряє розташування для підтвердження

Етап 3: Підтвердження активації
-------------------------------
1. Адміністратор натискає кнопку «Активувати прилад»
2. Програма показує QMessageBox.question:
   - "Активувати прилад SN: X?"
   - Кнопки: Yes / No

Етап 4: Активація в БД
----------------------
1. UPDATE devices SET is_active = 1 WHERE serial_number = ?
2. Оновлення кешу активних приладів: reload_devices_map()
3. Запис події:
   INSERT INTO system_events (device_id, timestamp, event_type, description)
   VALUES (NULL, datetime('now'), 'device_activated', 'Прилад X активовано')

Етап 5: Завершення
------------------
1. Виведення QMessageBox.information:
   - "Прилад X активовано. Необхідно перезапустити програму."
2. Оновлення тексту статусу в діалозі
3. Адміністратор закриває програму та запускає знову

8.4. ВІДМІННОСТІ ВІД ЗАМІНИ ПРИЛАДУ
-----------------------------------
| Характеристика | Заміна | Активація |
|----------------|--------|-----------|
| Зміна SN | Так (старий → новий) | Ні |
| Зміна адреси | Так (200/201 → цільова) | Ні |
| Зміна is_active | Старий = 0, новий = 1 | 0 → 1 |
| Потрібен фізичний прилад | Так (адреса 200-201) | Ні |
| Пошук нового приладу | Так | Ні |
| Використовує AddressChanger | Так | Ні |

8.5. АВТОМАТИЧНА АКТИВАЦІЯ ПРИ ПОШУКУ
-------------------------------------
Якщо прилад фізично знайдено під час пошуку (scan_devices), але в БД він is_active = 0:

1. Програма автоматично активує прилад
2. Змінює is_active = 1 в БД
3. Записує подію device_activated
4. Виводить повідомлення в лог:
   "Прилад X автоматично активовано при пошуку"

Це забезпечує безшовне повернення приладу після ремонту.

8.6. ПРИКЛАД ВИКОРИСТАННЯ
--------------------------
Сценарій: Прилад 2400089 був замінений на 2400123. Через тиждень
2400089 повернули після ремонту.

Дії адміністратора:
1. Фізично підключити 2400089 (адреса 1, вільна)
2. Запустити програму
3. Відкрити діалог заміни/активації
4. Вибрати 2400089 в списку неактивних
5. Натиснути «Активувати прилад»
6. Перезапустити програму

Результат:
- Прилад 2400089 знову активний
- Дані опитуються та зберігаються
- Історія вимірювань не втрачена

8.7. ОБРОБКА ПОМИЛОК
--------------------
| Помилка | Дія |
|---------|-----|
| Не вибрано прилад | QMessageBox.warning "Не вибрано прилад для активації" |
| Помилка UPDATE в БД | Виведення помилки, активація скасовується |

8.8. КОД АКТИВАЦІЇ (МЕТОД ДІАЛОГУ)
----------------------------------
```python
def activate_device(self):
    """Активує вибраний неактивний прилад"""
    sn = self.ui.combo_inactive_device.currentData()
    if not sn:
        QMessageBox.warning(self, "Помилка", "Не вибрано прилад для активації")
        return
    
    reply = QMessageBox.question(self, "Підтвердження", 
                                  f"Активувати прилад {sn}?",
                                  QMessageBox.Yes | QMessageBox.No)
    if reply != QMessageBox.Yes:
        return
    
    self.db_manager.activate_device(sn)
    self.db_manager.reload_devices_map()
    
    self.db_manager.save_system_event(None, "device_activated", f"Прилад {sn} активовано")
    
    QMessageBox.information(self, "Успіх", f"Прилад {sn} активовано. Необхідно перезапустити програму.")
    self.ui.label_status.setText("Прилад активовано. Перезапустіть програму.")

8.9. ПРИМІТКИ

Активація не вимагає фізичної присутності приладу на шині

Активація не змінює адресу приладу

Після активації потрібен перезапуск програми для оновлення GUI

Автоматична активація під час пошуку працює тільки для фізично присутніх приладів
