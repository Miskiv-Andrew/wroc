3. Структура бази даних (SQLite)
Файл: data/clinic.db

Таблиця devices — прилади
Поле	Тип	Обмеження	Опис
id	INTEGER	PRIMARY KEY AUTOINCREMENT	Унікальний ідентифікатор
serial_number	TEXT	UNIQUE NOT NULL	Серійний номер приладу
device_type	TEXT	NOT NULL	Тип приладу ("БДБГ-09S-23")
location_type	TEXT	NOT NULL	Тип розташування ("cistern" / "room")
position_number	INTEGER	NOT NULL	Номер цистерни або кімнати
is_active	INTEGER	DEFAULT 1	1 — активний, 0 — неактивний (замінений)
Приклад даних:

sql
INSERT INTO devices (serial_number, device_type, location_type, position_number, is_active)
VALUES ('2400089', 'БДБГ-09S-23', 'cistern', 1, 1);
Таблиця measurements_wall — вимірювання настінних детекторів
Поле	Тип	Обмеження	Опис
id	INTEGER	PRIMARY KEY AUTOINCREMENT	
device_id	INTEGER	NOT NULL, FOREIGN KEY → devices(id)	Посилання на прилад
timestamp	DATETIME	NOT NULL	Час вимірювання (YYYY-MM-DD HH:MM:SS)
paed	REAL	NOT NULL	ПАЕД (мкЗв/рік)
temperature	REAL	NOT NULL	Температура (°C)
low_status	INTEGER	NOT NULL	Низькочутливий детектор: 0=норма, 1=відмова
high_status	INTEGER	NOT NULL	Високочутливий детектор: 0=норма, 1=відмова
valid	INTEGER	NOT NULL	Валідність результату: 0=невалідний, 1=валідний
Буферизація: Запис відбувається раз на 30 хвилин (останнє вимірювання для кожного приладу).

Таблиця measurements_cistern — вимірювання цистерн
Поле	Тип	Обмеження	Опис
id	INTEGER	PRIMARY KEY AUTOINCREMENT	
device_id	INTEGER	NOT NULL, FOREIGN KEY → devices(id)	Посилання на прилад
timestamp	DATETIME	NOT NULL	Час вимірювання
paed	REAL	NOT NULL	ПАЕД (мкЗв/рік)
activity	REAL	NOT NULL	Активність (Бк)
low_status	INTEGER	NOT NULL	Низькочутливий детектор
high_status	INTEGER	NOT NULL	Високочутливий детектор
valid	INTEGER	NOT NULL	Валідність результату
fullness_status	TEXT	NOT NULL	Стан цистерни: "full" / "empty"
ready_to_drain	INTEGER	NOT NULL	Готовність до зливу: 0=ні, 1=так
Запис: Кожне вимірювання зберігається негайно (без буферизації).

Таблиця system_events — системні події
Поле	Тип	Обмеження	Опис
id	INTEGER	PRIMARY KEY AUTOINCREMENT	
device_id	INTEGER	NULL, FOREIGN KEY → devices(id)	Посилання на прилад (може бути NULL)
timestamp	DATETIME	NOT NULL	Час події
event_type	TEXT	NOT NULL	Тип події
description	TEXT		Опис події
Типи подій (event_type):

Значення	Опис
app_start	Запуск програми
app_stop	Зупинка програми
device_replaced	Заміна приладу
device_activated	Активація приладу (ручна або автоматична)
cistern_filled	Заповнення цистерни
cistern_drained	Злив цистерни
connection_error	Втрата зв'язку з приладом (5 невідповідей)
crc_error	Помилка CRC пакета
spectrum_reset	Скидання спектру
start_spectre_failed	Невдалий запуск набору спектру (3 спроби)
Індекси (для оптимізації запитів)
sql
CREATE INDEX idx_wall_timestamp ON measurements_wall(timestamp);
CREATE INDEX idx_cistern_timestamp ON measurements_cistern(timestamp);
CREATE INDEX idx_events_timestamp ON system_events(timestamp);
CREATE INDEX idx_events_device ON system_events(device_id);
CREATE INDEX idx_wall_device ON measurements_wall(device_id);
CREATE INDEX idx_cistern_device ON measurements_cistern(device_id);
Очищення старих даних
Записи старіші за 3 роки автоматично видаляються з усіх таблиць

Перевірка відбувається при запуску програми та кожні 24 години

sql
DELETE FROM measurements_wall WHERE timestamp < datetime('now', '-3 years');
DELETE FROM measurements_cistern WHERE timestamp < datetime('now', '-3 years');
DELETE FROM system_events WHERE timestamp < datetime('now', '-3 years');
