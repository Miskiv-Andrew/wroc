11. ІНСТРУКЦІЯ З РОЗГОРТАННЯ ТА НАЛАШТУВАННЯ
==============================================

11.1. СИСТЕМНІ ВИМОГИ
---------------------
- Операційна система: Windows 10/11 (64-bit)
- Процесор: Intel Core i3 або аналогічний
- ОЗП: 4 GB (рекомендується 8 GB)
- Диск: 1 GB вільного місця (для БД та логів)
- COM-порти: доступні порти для підключення RPII
- Монітор: 1280x720 або вище

11.2. ПРОГРАМНЕ ЗАБЕЗПЕЧЕННЯ
-----------------------------
- Python 3.14 або вище
- Бібліотеки (встановлюються автоматично):
  * PySide6
  * matplotlib
  * numpy
  * pyserial
  * pyside6-essentials

11.3. ВСТАНОВЛЕННЯ
------------------
11.3.1. Встановлення Python
  1. Завантажити Python 3.14 з офіційного сайту
  2. Запустити інсталятор
  3. Обов'язково відмітити "Add Python to PATH"
  4. Виконати інсталяцію

11.3.2. Встановлення залежностей
  Відкрити командний рядок (cmd) в папці проекту та виконати:
  
  pip install -r requirements.txt

  Або вручну:
  pip install PySide6 matplotlib numpy pyserial

11.4. ПЕРШЕ НАЛАШТУВАННЯ (ДЛЯ ІНЖЕНЕРІВ)
-----------------------------------------
11.4.1. Підключення обладнання
  1. Підключити розширювачі портів RPII до COM-портів комп'ютера
  2. Підключити прилади БДБГ-09S-23 до RPII (адресація 1-6)
  3. Переконатися, що драйвери FTDI встановлені

11.4.2. Перший запуск (режим налагодження)
  1. Відкрити файл devices/device_manager.py
  2. Знайти рядок: self.debug_mode: int | None = None
  3. Змінити на: self.debug_mode = 1
  4. Зберегти файл
  5. Запустити програму: python app.py
  6. Натиснути «Пошук приладів»
  7. Програма створить config.txt, hash.txt, cistern.json
  8. Закрити програму
  9. Повернути self.debug_mode = None
  10. Зберегти файл

11.4.3. Налаштування словників приладів
  У файлі devices/device_manager.py знайти та відредагувати:

  self.cistern_dict = {"2400089": 1, "2400090": 2}   # SN: номер цистерни
  self.room_dict = {"2400126": 1, "2400127": 2, "2400128": 3}   # SN: номер кімнати

11.5. НАЛАШТУВАННЯ КОНФІГУРАЦІЙНИХ ФАЙЛІВ
----------------------------------------
11.5.1. config.txt (створюється автоматично)
  Формат: serial_number;location_type;position_number;address
  Приклад:
    # serial_number;location_type;position_number;address
    2400089;cistern;1;1
    2400126;room;1;2
    2400127;room;2;3
    2400128;room;3;4

11.5.2. hash.txt (створюється автоматично)
  Містить SHA-256 хеш config.txt. Не редагувати вручну.

11.5.3. cistern.json (створюється автоматично)
  Формат: {"номер_цистерни": true/false}
  true — цистерна повна, false — порожня.

11.6. ЗВ'ЯЗОК ІЗ ЗОВНІШНЬОЮ СИСТЕМОЮ УПРАВЛІННЯ (HMI)
----------------------------------------------------
11.6.1. Modbus TCP налаштування
  ПЗ Екотест виступає в ролі клієнта (Master), HMI — сервера (Slave)

11.6.2. Дані від HMI до ПЗ
  - Стан заповненості цистерн (читання з регістрів HMI)

11.6.3. Дані від ПЗ до HMI
  - ПАЕД кожного приладу
  - Температура
  - Активність цистерн
  - Статус детекторів
  - Статус зв'язку
  - Системні події

11.7. ЗАПУСК ПРОГРАМИ
---------------------
11.7.1. Звичайний запуск
  python app.py

11.7.2. Створення ярлика (Windows)
  1. Правою кнопкою на робочому столі → Створити → Ярлик
  2. Шлях: python.exe шлях_до_projects\app.py
  3. Назва: Екотест

11.8. ПЕРШИЙ ЗАПУСК ПІСЛЯ НАЛАШТУВАННЯ
--------------------------------------
1. Запустити програму
2. Натиснути «Пошук приладів»
3. Переконатися, що всі прилади знайдені
4. Натиснути «Старт системи»
5. Перевірити появу даних на картках приладів

11.9. ТИПОВІ ПРОБЛЕМИ ТА РІШЕННЯ
--------------------------------
11.9.1. Помилка "Не знайдено жодного розширювачу портів RPII"
  Рішення:
  1. Перевірити підключення RPII
  2. Перевірити драйвера FTDI в Диспетчері пристроїв
  3. Перезавантажити комп'ютер

11.9.2. Помилка "Файл config.txt пошкоджений"
  Рішення:
  1. Видалити config.txt та hash.txt
  2. Встановити debug_mode = 1
  3. Виконати пошук приладів
  4. Повернути debug_mode = None

11.9.3. Прилад не відповідає (is_online = False)
  Рішення:
  1. Перевірити фізичне підключення приладу
  2. Перевірити адресу приладу (повинна збігатися з config.txt)
  3. Перезапустити програму

11.9.4. Помилка "Прилад не знайдено в БД"
  Рішення:
  1. Перевірити наявність запису в таблиці devices
  2. Якщо немає — додати вручну через DB Browser
  3. Або виконати пошук з debug_mode = 1

11.10. ОНОВЛЕННЯ ПРОГРАМИ

2. Замінити файли в папці проекту
