6. ОПИС ІНТЕРФЕЙСУ КОРИСТУВАЧА
===============================

6.1. ГОЛОВНЕ ВІКНО (main_window_form.ui)
-----------------------------------------
Файл: _UI/main_window_form.ui
Клас: App (завантажує та керує)

Структура:
- Головне меню
- Область карток приладів (розділена на дві частини)
- Поле логування (QTextEdit, тільки читання)

6.2. ГОЛОВНЕ МЕНЮ
------------------
Меню "Прилади":
- Пошук приладів
- Старт системи
- Зупинка системи
- Заміна приладу

Меню "База даних":
- Відкрити БД

6.3. КНОПКИ ТА ЇХ ПРИЗНАЧЕННЯ
------------------------------
| Назва | Дія |
|-------|-----|
| Пошук приладів | Сканування COM-портів, пошук приладів на адресах 1-6, створення карток |
| Старт системи | Запуск циклічного опитування приладів |
| Зупинка системи | Зупинка опитування, закриття COM-порту |
| Заміна приладу | Відкриття діалогу заміни/активації приладів |
| Відкрити БД | Відкриття вікна перегляду бази даних |

Стан кнопок:
- Після запуску програми: Пошук = активна, Старт = неактивна, Зупинка = неактивна
- Після пошуку: Пошук = активна, Старт = активна, Зупинка = неактивна
- Після старту опитування: Пошук = неактивна, Старт = неактивна, Зупинка = активна
- Після зупинки: Пошук = активна, Старт = активна, Зупинка = неактивна

6.4. КАРТКА ПРИЛАДУ (ЗАГАЛЬНА СТРУКТУРА)
-----------------------------------------
Кожен прилад відображається в окремій картці. Тип картки залежить від location_type.

Загальні елементи:
- SN: серійний номер
- Позиція (цистерна № або детектор №)
- ПАЕД (мкЗв/рік)
- Температура (°C)
- Статус зв'язку (Норма/Немає зв'язку)
- Статус детекторів (Норма/Відмова)
- Валідність результатів (Норма/Невалідний)

6.5. КАРТКА ЦИСТЕРНИ (DeviceCardBarrel)
---------------------------------------
Файл: _UI/dashboardbarrel.ui
Клас: DeviceCardBarrel (app.py)

Додаткові елементи:
- Зображення цистерни (повна/порожня)
- Активність (Бк)
- Ізотоп (заглушка)
- Готовність до зливу
- Вкладка "Спектр" (графік спектру в реальному часі)
- Вкладка "Гістограма" (графік активності за кнопкою)

Вкладка "Спектр":
- Відображає накопичений спектр (1024 канали)
- Оновлюється після кожного отриманого пакету GetSpectre

Вкладка "Гістограма":
- Два поля вибору дати (від/до)
- Кнопка "Побудувати"
- Графік активності за обраний період

6.6. КАРТКА НАСТІННОГО ДЕТЕКТОРА (DeviceCardWall)
-------------------------------------------------
Файл: _UI/dashboardwall.ui
Клас: DeviceCardWall (app.py)

Особливості:
- Немає зображення цистерни
- Немає активності та готовності до зливу
- Немає вкладок (тільки основна інформація)

6.7. ВІКНО ПЕРЕГЛЯДУ БАЗИ ДАНИХ (DBViewWindow)
-----------------------------------------------
Файл: _UI/db_view.ui
Клас: DBViewWindow (database/db_view_window.py)

Структура: QTabWidget з трьома вкладками

Вкладка "ПАЕД":
- Фільтри:
  * Діапазон дат (від/до) з календарем
  * Кнопка "За весь період"
  * Тип розташування (Всі/Цистерна/Кімната)
  * Прилад (випадаючий список, залежить від типу)
  * Кнопка "Показати"
- Графік ПАЕД від часу (верхня половина)
- Таблиця з даними (нижня половина)
- Кнопки: Експорт CSV, Зберегти графік PNG, Скинути фільтри

Вкладка "Активність":
- Фільтри:
  * Діапазон дат (від/до)
  * Кнопка "За весь період"
  * Цистерна (випадаючий список)
  * Кнопка "Показати"
- Графік активності від часу
- Таблиця з даними
- Кнопки: Експорт CSV, Зберегти графік PNG, Скинути фільтри

Вкладка "Системні події":
- Фільтри:
  * Діапазон дат (від/до)
  * Кнопка "За весь період"
  * Тип події (випадаючий список)
  * Прилад (випадаючий список)
  * Кнопка "Показати"
- Таблиця подій
- Кнопки: Експорт CSV, Скинути фільтри

6.8. ДІАЛОГ ЗАМІНИ/АКТИВАЦІЇ ПРИЛАДУ (DeviceReplaceDialog)
----------------------------------------------------------
Файл: _UI/device_replace.ui
Клас: DeviceReplaceDialog (dialogs/device_replace_dialog.py)

Структура:

Група "1. Заміна приладу":
- Прилад, що замінюється (активний): випадаючий список
- Розташування (відображається автоматично)
- Новий SN: поле (тільки читання)
- Кнопка "Знайти новий прилад"

Група "2. Активація приладу":
- Неактивний прилад: випадаючий список
- Кнопка "Активувати прилад"

Поле статусу (QLabel) – відображає результат операції

Кнопки:
- Виконати заміну (активна тільки після знаходження нового приладу)
- Скасувати

6.9. ПОЛЕ ЛОГУВАННЯ (QTextEdit)
-------------------------------
- Розташоване в нижній частині головного вікна
- Тільки читання
- Відображає:
  * Результати пошуку приладів
  * Статус опитування
  * Отримані значення ПАЕД та температури
  * Помилки (CRC, таймаут, конфігурація)
  * Системні повідомлення (активація, заміна)

6.10. СТАТУСИ ВІДОБРАЖЕННЯ
---------------------------
Статус зв'язку:
- Норма (зелений)
- Немає зв'язку (червоний)

Статус детекторів:
- Норма (зелений)
- Відмова (червоний)

Валідність результатів:
- Норма (зелений)
- Невалідний (червоний)

Стан цистерни:
- Повна (іконка barrelfull.svg)
- Порожня (іконка barrelempty.svg)

6.11. КОМБІНАЦІЇ КЛАВІШ
-----------------------
- Alt+F4 – закриття програми
- (Інші комбінації відсутні)

6.12. ПОВІДОМЛЕННЯ ПРО ПОМИЛКИ
-------------------------------
- QMessageBox.warning – для критичних помилок (немає приладів, помилка конфігурації)
- QMessageBox.information – для інформаційних повідомлень (активація, заміна)
- QMessageBox.question – для підтвердження дій (активація приладу)
