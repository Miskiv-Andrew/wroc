Пошук приладів відбувається після кліку на кнопці "Пошук підключених приладів"

 						   
1.  Для роботи системи використовуємо 3 файли ( усі у папці "config" )
		- config.txt 
		
		# serial_number;location_type;posit_number;address
		2400126;room;1;2
		2400127;room;2;3
		2400089;cistern;1;1
		2400128;room;3;4
		
		serial_number - серійний номер
		location_type - цистерна або приміщення
		posit_number  - номер цистерни або в приміщенні
		address       - адреса приладу для запитів
		
		
		- hash.txt 
		335ac0f10cd84bab441eb7430a41dcc9eb318888040bce3f08f1e9c75aa27fcc
		
		При створенні нового config.txt обраховуємо його хеш і пишемо в hash.tx - при  старті
        програми перевіряємо, чи не був змінений config.txt - якщо файл налаштувань змінився,
        роботу системи не починаємо, на весь єкран - CONFIG ERROR !!! 	


		

		- cistern.json
		{
			"1": false
		}
		Ключами слугують номери цистерн, значення - повна(True) або порожня(False) цистерна.
		По дефолту усі цистерни порожні. Дані про заповнення будемо отримувати від зовнішньої системи
		керування ( це буде пізніше). Сумістити прилади з цистернами ми зможемо по номеру цистерни
		
                            
							    1 ЕТАП ( пошук приладів )

1. self.ui.butt_search_dev.clicked.connect(self.device_manager.find_rpii_ports) - конект кнопки та слота 
2. def find_rpii_ports(self)  - шукає всі підключені RTII за ознакою FTDI
	- якщо щось знайдено, викликається def scan_devices(self)
3. def scan_devices(self)  - у зовнішньому циклі йдемо по знайдених СОМ-портах RTII;
   у внутрішньому циклі йдемо по адресах (поки що від 1 до 6 включно) і відправляємо запити 
   з серійним номером;
   Для приладу, який "відгукнувся", створюємо об'ект DeviceInfo, заповнюємо ті дані, які
   вже маємо, і вносимо прилад в self.devices: list[DeviceInfo] = []  - список знайдених приладів
   
   
                               2 ЕТАП ( налагодження роботи системи )	


1.  У режимі налагодження програма шукає прилади, по результатам пошуку створює усі необхідні кофігураційні файли у відповідності до реального підключення.
    Дії програміста у файлі device_manager.py :
		- self.debug_mode = 1 
		- self.cistern_dict = {"2400089" : 1}                                   - заповнити словник приладів у цистернах з номерами цистерн
		- self.room_dict    = {"2400126" : 1, "2400127" : 2,  "2400128" : 3}    - заповнити словник приладів у кімнатах з номерами місць розташування
		- запустити "Пошук підключених приладів"   - результат має бути таким:
		
		
			Знайдено прилади:
			Порт: COM7, Адреса: 2, SN: 2400126
			Порт: COM7, Адреса: 3, SN: 2400127
			Порт: COM8, Адреса: 1, SN: 2400089
			Порт: COM8, Адреса: 4, SN: 2400128

			Нові дані занесено у файли конфігурації
			
			
	Цей режим тільки для створення необхідних конфігураційних файлів.
	
	
								3 ЕТАП ( нормальна робота системи )
	

1.  У робочому режимі програма шукає прилади, перевіряє відповідність конфігураційним файлам, та виводить резудльтати пошуку	
	Дії програміста у файлі device_manager.py :
		- self.debug_mode = None
		- запустити "Пошук підключених приладів"   - результат має бути таким:
		
			Знайдено прилади:
			Порт: COM7, Адреса: 2, SN: 2400126
			Порт: COM7, Адреса: 3, SN: 2400127
			Порт: COM8, Адреса: 1, SN: 2400089
			Порт: COM8, Адреса: 4, SN: 2400128
